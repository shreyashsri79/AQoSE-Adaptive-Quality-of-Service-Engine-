WHY NOTHING FIXES THIS TODAY
The router has to be told what each connection is.
Priority marks
CAKE does prioritise packets that carry a priority mark (DSCP). But most apps never set one, and ISPs often strip them.
Threshold rules
Tools like qosify say "many packets per second means bulk". An HD call sends 400–600 packets/s; a cloud game over 1,000.
On our sealed test set, qosify's default rules sent 78% of cloud-gaming flows and 14% of video calls to the slowest queue.
02 · HOW AQoSE WORKS
It reads only the first 8 packets of each new connection.
259 small decision trees turn them into odds.
Unsure? It weighs the odds against measured harm.
Then it writes one label, once.
8 packet sizes7 gapsports, protocol, IP version9 rate and burst stats
= 28 numbers
headers only, never content
≈ 0.13 s
after the connection opens
6 µs
per connection, in Go on the router.
LightGBM: 37 rounds × 7 classes = 259 trees.
Guards on top: Voice only if it's over 50% likely a call or game. Bulk only if over 80% sure, and never for UDP or a connection's first packets.
Written into the kernel's connection tracker, then read back to check.
CAKE applies it to every packet, both directions. AQoSE is never on the packet path: if it stops, packets still flow.
